OMniX  v1.4.2   —— 多游戏 Mod 管理器（鸣潮 / 绝区零 / 原神 / 崩铁）
=====================================

【先说一句：这个是免费的】
  OMniX 完全免费、开源，没有会员版，也没有激活码，没有任何要花钱才能用的功能。

  如果有人跟你要钱才给安装包，或者卖你「激活码」「会员版」——那就是骗子。
  直接拒绝就好，顺手到交流群或者 GitHub 上说一声，别让下一个人上当。

  正经的来源只有两个：
    1. GitHub 的 Releases 页面（https://github.com/aiertana/OMnix/releases）
    2. 交流群里的群文件
  其它渠道下载到的安装包，请不要用。

  交流群二维码、微信/支付宝投喂码，程序里点左下角「关于」都能看到。


【怎么打开】
  解压整个文件夹之后，双击里面的「启动OMniX.exe」。
  它不会弹出黑色命令行窗口，会直接把程序拉起来。
  （直接双击 OMniX\OMniX.exe 也行，效果一样）

  第一次打开可能会慢一点（自包含版本要解压运行时），
  之后就快了。不需要你另外装 .NET。


【第一次用要做什么】
  1. 打开后直接进首页。鸣潮是内置内核，开箱即用；
     绝区零 / 原神 / 崩铁要在首页右上角切换游戏，按提示下载对应内核，
     也可以在「功能专区」里导入离线 zip 包
  2. 首页点「配置游戏」设置路径：
     · 鸣潮：指向官方启动器或游戏目录
     · 绝区零：指向 XXMI Launcher 所在的目录，例如 D:\mod\XXMI Launcher，
       程序会自动认出启动程序，并推导出 Mods 文件夹
  3. 还没装 XXMI Launcher 的话，工具栏上点「启动器」按钮，
     会提示你去 GitHub 下载，或者自己手动指定路径

  启动方式会按游戏自动识别：鸣潮走官方启动器、绝区零走 XXMI、
  原神 / 崩铁走 HoYo 系启动器；识别不到就在设置里手动指定一个 exe。

  注意：Mod 文件本体不在 OMniX 里 —— 鸣潮在 XXMI Launcher 的 WWMI\Mods 里，
  其它游戏按各自的 Mods 目录走，这个管理器只是引用它们，不自带任何 Mod。


【能改的东西】
  右上角齿轮进设置，里面有主题、数据目录、游戏路径、清理等。
  常用操作：
    · 首页右上角：切换游戏内核（会重启程序）
    · 角色管理页：所有角色的头像墙，选角色直接开/关 Mod
    · Mod 预设：把一套 Mod 组合存成预设，一键切换
    · 功能专区：管理各游戏的内核与插件，可下载、可导入离线包
    · 置顶的针：只有你手动点的那一下才会亮，应用预设不会自动亮


【数据存在哪】
  数据在程序目录下，按游戏分开存放（可以在设置里挪到别的盘）：

    OMniX1.4.2.x\
    ├─ Core\            管理器本体（OMniX.exe 在这里）
    ├─ GamesData\       游戏数据，按游戏分目录
    │  ├─ WuWa\         鸣潮：Presets\ Plugins\ Cache\ Logs\
    │  ├─ ZZZ\          绝区零
    │  ├─ GI\           原神
    │  └─ HSR\          崩坏：星穹铁道
    ├─ 启动OMniX.exe
    └─ 手动更新.exe

  老版本的数据在 C:\Users\<你的用户名>\AppData\Local\OMniX\ 里。
  升级上来后软件会问你要不要一键搬过来，也可以在
  「设置 → 游戏与路径 → 数据目录」里手动迁移。搬不搬、搬完删不删都由你决定。
