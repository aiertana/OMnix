OMniX  v1.1.8   —— 鸣潮 Mod 管理器
=====================================

【先说一句：这个是免费的】
  OMniX 完全免费、开源，没有会员版，也没有激活码，没有任何要花钱才能用的功能。

  如果有人跟你要钱才给安装包，或者卖你「激活码」「会员版」——那就是骗子。
  直接拒绝就好，顺手到交流群或者 GitHub 上说一声，别让下一个人上当。

  正经的来源只有两个：
    1. GitHub 的 Releases 页面（https://github.com/aiertana/OMnix/releases）
    2. 交流群里的群文件
  其它渠道下载到的安装包，请不要用。

  交流群二维码、微信/支付宝投喂码，程序里点左下角「关于」都能看到。


【怎么打开】
  解压整个文件夹之后，双击里面的「启动OMniX.exe」。
  它不会弹出黑色命令行窗口，会直接把程序拉起来。
  （直接双击 OMniX\OMniX.exe 也行，效果一样）

  第一次打开可能会慢一点（自包含版本要解压运行时），
  之后就快了。不需要你另外装 .NET。


【第一次用要做什么】
  1. 程序会先进「首次启动」引导页，游戏选「鸣潮」
  2. 它会问你 XXMI Launcher 的文件夹在哪 —— 选 XXMI Launcher 所在的目录，
     例如 D:\mod\XXMI Launcher
     进去之后程序会自动认出启动程序，并推导出 Mods 文件夹
  3. 还没装 XXMI Launcher 的话，工具栏上点「启动器」按钮，
     会提示你去 GitHub 下载，或者自己手动指定路径

  注意：Mod 文件本体放在 XXMI Launcher 的 WWMI\Mods 里，
  这个管理器只是引用它们，不自带任何 Mod。


【能改的东西】
  右上角齿轮进设置，里面有热重载开关、主题、Mod 文件夹路径等。
  常用操作：
    · 角色管理页：所有角色的头像墙，选角色直接开/关 Mod
    · Mod 预设：把一套 Mod 组合存成预设，一键切换
    · 置顶的针：只有你手动点的那一下才会亮，应用预设不会自动亮


【数据存在哪】
  C:\Users\<你的用户名>\AppData\Local\OMniX\ApplicationData_WuWa
  角色、预设、自定义头像都在这里。
